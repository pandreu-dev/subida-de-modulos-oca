# Pruebas WIP

1. Calcular WIP de un presupuesto con proyecto.
2. Crear asiento WIP.
3. Comprobar que las lineas contables con analitica tienen `Proyecto WIP`.
4. Comprobar que la distribucion analitica del asiento no esta al `0%`.
5. Abrir apuntes analiticos.
6. Agrupar por proyecto.
7. Confirmar que las lineas WIP aparecen bajo el proyecto correcto y con importe.
8. Confirmar que PyG sigue mostrando los mismos importes que antes.
9. Abrir un calculo WIP que ya tuviera asiento creado antes de instalar el modulo.
10. Volver a agrupar apuntes analiticos por proyecto y confirmar que tambien queda enlazado.
