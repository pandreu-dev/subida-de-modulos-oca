# Pruebas WIP

1. Calcular WIP de un presupuesto con proyecto.
2. Crear asiento WIP.
3. Comprobar que las lineas contables con analitica tienen `Proyecto WIP`.
4. Abrir apuntes analiticos.
5. Agrupar por proyecto.
6. Confirmar que las lineas WIP aparecen bajo el proyecto correcto.
7. Confirmar que PyG sigue mostrando los mismos importes que antes.
8. Abrir un calculo WIP que ya tuviera asiento creado antes de instalar el modulo.
9. Volver a agrupar apuntes analiticos por proyecto y confirmar que tambien queda enlazado.
