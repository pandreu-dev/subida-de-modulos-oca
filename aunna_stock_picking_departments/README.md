# AUNNA Stock Picking Departments

## Objetivo

Anade departamentos BR en albaranes y pedidos de compra.

## Funcionamiento

- Recepciones: muestra `Departamento de entrada`.
- Entregas: muestra `Departamento de salida`.
- Traspasos internos: muestra entrada y salida.
- Pedido de compra: el departamento indicado se copia al albaran de recepcion generado al confirmar.

## Configuracion

Ruta:

`Inventario > Configuracion > Departamentos BR`

Departamentos iniciales:

- Comun
- Despliegue
- Radio
- Fotovoltaica

## Lista de albaranes

La lista muestra:

- `Departamento salida`
- `Departamento entrada`
- `Valor`

Tambien se puede buscar por departamento general, departamento de salida o departamento de entrada desde el buscador de albaranes.
